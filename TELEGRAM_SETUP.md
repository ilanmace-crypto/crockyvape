# Настройка Telegram Bot для авторизации

Для работы системы авторизации через Telegram необходимо создать бота и настроить его.

## Шаг 1: Создание Telegram бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: `Paradis Shop Bot`)
   - Введите username бота (например: `paradis_shop_bot` - должен заканчиваться на `bot`)
4. BotFather пришлет вам **API Token**. Сохраните его, он понадобится дальше.

## Шаг 2: Настройка переменных окружения

Добавьте следующие переменные в ваш файл `.env` в папке `server/`:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TELEGRAM_BOT_USERNAME=ваш_username_бота_без_собаки
```

Пример:
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_BOT_USERNAME=paradis_shop_bot
```

## Шаг 3: Настройка клиента

Добавьте переменную в файл `.env` в папке `client/`:

```env
VITE_TELEGRAM_BOT_USERNAME=ваш_username_бота_без_собаки
```

Пример:
```env
VITE_TELEGRAM_BOT_USERNAME=paradis_shop_bot
```

## Шаг 4: Обновление базы данных

Запустите миграцию базы данных для добавления поля `is_blocked` в таблицу users:

```bash
cd server
# Если используете PostgreSQL/Supabase
psql -U ваш_юзер -d ваша_база -f database_schema.sql

# Или через скрипт автонастройки
node auto_setup_database.js
```

## Шаг 5: Перезапуск сервера

После настройки переменных окружения перезапустите сервер:

```bash
cd server
npm start
```

## Как это работает

1. **Авторизация**: Пользователь нажимает кнопку "Login via Telegram" на сайте
2. **Telegram Widget**: Открывается окно авторизации Telegram, пользователь подтверждает вход
3. **Проверка**: Сервер проверяет подпись данных от Telegram с помощью Bot Token
4. **Создание/обновление пользователя**: Пользователь создается или обновляется в базе данных
5. **Сессия**: Данные пользователя сохраняются в localStorage и используются для заказов и отзывов

## Управление пользователями

В админ-панели появилась новая вкладка "Пользователи", где можно:

- Просматривать список всех пользователей
- Видеть их Telegram ID, username, количество заказов и общую сумму потраченного
- **Блокировать** пользователей - заблокированные пользователи не могут оформлять заказы и оставлять отзывы
- **Разблокировать** пользователей

## Безопасность

- Данные от Telegram проверяются криптографической подписью (HMAC-SHA256)
- Bot Token хранится в переменных окружения и не попадает в клиентский код
- Заблокированные пользователи не могут взаимодействовать с сайтом

## Troubleshooting

**Ошибка "Telegram bot token not configured"**
- Убедитесь, что `TELEGRAM_BOT_TOKEN` добавлен в `.env` файл сервера
- Перезапустите сервер после добавления переменной

**Ошибка "Invalid Telegram data"**
- Убедитесь, что Bot Token правильный
- Проверьте, что username бота указан верно в клиентском `.env`

**Виджет не отображается**
- Убедитесь, что скрипт Telegram Widget загружается в `index.html`
- Проверьте, что `VITE_TELEGRAM_BOT_USERNAME` указан в клиентском `.env`
